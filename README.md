# Completa Album

Aplicacao web para acompanhar uma colecao de figurinhas da Copa do Mundo 2026.

## Versao atual

**v2.0.0**

## Destaques da versao 2.0.0

- Nova identidade visual com estilo de album esportivo.
- Navegacao rapida por grupos.
- Filtro para mostrar somente figurinhas faltantes.
- Experiencia otimizada para celulares.
- Aplicacao instalavel como PWA.
- Painel de progresso e resumo da colecao.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven Wrapper
- HTML, CSS e JavaScript

## Desenvolvimento local

```powershell
./mvnw.cmd spring-boot:run
```

Depois, acesse `http://localhost:8080`.

## Testes

```powershell
./mvnw.cmd test
```
